# [akhilaariyachandra.com](https://akhilaariyachandra.com/)

[![code style: prettier](https://img.shields.io/badge/code_style-prettier-ff69b4.svg?style=flat-square)](https://github.com/prettier/prettier)

This site is built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), [Sanity](https://www.sanity.io/), & [Vercel](https://vercel.com/home).

## Environment Variables

Environment Variables are handled through [Varlock](https://varlock.dev/) so check the [`.env.schema` file](/.env.schema) so which variables are needed

## Actions

### Running in development mode

```shell
pnpm run dev
```

### Running in production mode

```shell
pnpm run build
pnpm run start
```

### Formatting the code

```shell
pnpm run prettier:format
```
